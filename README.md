# 🚀 F_Zon3

F_Zon3 is a modern social media web application inspired by Instagram. It allows users to connect, share posts, interact with others, and enjoy a smooth and responsive experience.

## 🌐 Live Demo

🔗 **Deployed Website:** https://f-zon3-mhl2.vercel.app/

## 📂 Repository

🔗 **GitHub Repository:** https://github.com/PRUDHVI0143/F_Zon3

## ✨ Features

* 🔐 User authentication and authorization
* 📸 Upload and share posts
* ❤️ Like and interact with posts
* 👥 User profiles
* 💬 Comment system
* 🔍 Search functionality
* 📱 Fully responsive design
* ⚡ Fast and modern UI

## 🛠️ Tech Stack

### Frontend

* React.js
* JavaScript
* Tailwind CSS
* HTML5
* CSS3

### Backend

* Node.js
* Express.js

### Database

* MongoDB

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/PRUDHVI0143/F_Zon3.git
```

Move into the project directory:

```bash
cd F_Zon3
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
